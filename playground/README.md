# Playground — Hands-On Engineering Lab

Use these folders to write, break, benchmark, and verify real code across all 8 pillars:

- `dsa/` — Java DSA implementations + JUnit edge-case tests (brute force vs optimal)
- `java-spring/` — Spring Boot mini-services, JPA N+1 labs, `@Transactional` & concurrency experiments
- `dbms/` — PostgreSQL/MySQL schemas, slow queries, `EXPLAIN (ANALYZE, BUFFERS)` benchmarks, Redis scripts
- `os-linux/` — JVM memory/GC/thread dumps, cgroups/Docker OOM experiments, Linux networking & `epoll` notes
- `gcp/` — Cloud Run / GKE / IAM / PubSub / Cloud SQL Terraform & config templates
- `google-ai/` — Gemini API / Vertex AI Java & Python experiments, structured outputs, RAG & eval harnesses
- `system-design/` — Architecture diagrams, capacity math sheets, and mini-ADRs
