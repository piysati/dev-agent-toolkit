# /retro-pattern — Capture Session Learnings Into Muscle Memory

Run at the end of a study session, DSA practice, debugging war story, or work feature to convert short-term insights into permanent engineering instincts.

## Steps

1. **Review the current session** for:
   - Recurring problem signals & patterns solved
   - Bugs, misconceptions, or bottlenecks caught
   - Trade-offs weighed and rejected alternatives
2. **Draft Concise Entries**:
   - For repeatable patterns / coding / debugging insights → format an entry for `journal/pattern-bank.md` with today's date and a +3 day spaced-repetition review date.
   - For design/architecture choices → format a mini-ADR entry for `journal/tradeoff-log.md`.
   - If a roadmap milestone was mastered hands-on → suggest checking it off in `journal/roadmap-tracker.md`.
3. **Confirm & Write**: Show the drafted entries to the user and append them to the journal files once approved.
4. **Suggest Next Drill**: Recommend the highest-leverage next topic or due review item for tomorrow's session.
